# Comprobación anterior del portal

El workflow de este repositorio está **desactivado** desde el 13 de noviembre de 2026. La comprobación activa se trasladó al programador del proveedor de la base de datos y se verificaron ejecuciones reales.

Este repositorio conserva únicamente la prueba de las direcciones públicas de https://ucsg-calidad.onrender.com y su documentación. Las ejecuciones anteriores están en la pestaña Actions. No representa el estado actual del portal.

El portal institucional, sus documentos y sus credenciales se administran de forma privada. Las modalidades gratuitas conservan sus condiciones y no garantizan disponibilidad continua.
